# Account Logo Assets

This folder is reserved for official account, bank, and wallet logo assets.

Do not add logos copied from search results or third-party logo aggregators. For a public repository, only add files that come from an official brand/media kit or files you have permission to use.

The app currently uses brand-style text badges from `src/data/accountBrands.ts` so it can look polished without bundling trademarked logo files.
